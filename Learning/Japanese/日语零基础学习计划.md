# 日语零基础学习计划

> 适用：完全零基础，以中文为母语。
> 主线：JLPT 能力考体系（最通用、有明确里程碑）。
> 默认假设：每个工作日 60–90 分钟，周末各一次 2 小时。若时间不同，按文末「时间表调整」一节缩放。
> 最后更新时间：2026-10-15

## 2. 阶段详解

### 阶段 0（第 1–2 周）：五十音与发音

**这两周决定你后面所有听力的上限，不能跳过、不能压缩。**

目标：
- 平假名、片假名看到 1 秒内读出，听到能写出
- 掌握浊音、半浊音、拗音、促音、长音、拨音
- 不再依赖罗马音（第 8 天起强制脱罗马音）

每日安排（60 分钟）：
1. 15 分钟：抄写 1 行假名（笔顺要对，照着笔顺动画抄）
2. 15 分钟：Anki 复习 + 新卡
3. 15 分钟：听发音音频，跟读（大声，录音对比）
4. 15 分钟：拼读练习（用假名拼 20 个简单词：すし、てんぷら、ねこ、くるま…）

**达标标准：** 随机听到 20 个假名，能全部写对；看到一篇全假名的短文能读出来。

#### 五十音图（清音：平假名 / 片假名）

| 行＼段 | あ段 | い段 | う段 | え段 | お段 |
|---|---|---|---|---|---|
| あ行 | あ / ア (a) | い / イ (i) | う / ウ (u) | え / エ (e) | お / オ (o) |
| か行 | か / カ (ka) | き / キ (ki) | く / ク (ku) | け / ケ (ke) | こ / コ (ko) |
| さ行 | さ / サ (sa) | し / シ (shi) | す / ス (su) | せ / セ (se) | そ / ソ (so) |
| た行 | た / タ (ta) | ち / チ (chi) | つ / ツ (tsu) | て / テ (te) | と / ト (to) |
| な行 | な / ナ (na) | に / ニ (ni) | ぬ / ヌ (nu) | ね / ネ (ne) | の / ノ (no) |
| は行 | は / ハ (ha) | ひ / ヒ (hi) | ふ / フ (fu) | へ / ヘ (he) | ほ / ホ (ho) |
| ま行 | ま / マ (ma) | み / ミ (mi) | む / ム (mu) | め / メ (me) | も / モ (mo) |

| 拨音 | ん / ン (n) | | | | |

#### 必须额外掌握的发音规则

| 项目 | 规则 | 例 |
|---|---|---|
| 浊音 | か→が、さ→ざ、た→だ、は→ば（右上角加两点） | がくせい（学生） |
| 半浊音 | は→ぱ（右上角加圈） | パン（面包） |
| 拗音 | きゃ・しゅ・ちょ（小写やゆよ，算一拍） | きゃく（客） |
| 促音 | 小写っ，停顿一拍 | がっこう（学校） |
| 长音 | あ段后加あ、い段后加い… | おかあさん（妈妈） |
| 拨音 | ん，占一拍，不发"嗯"的鼻音就错 | でんわ（电话） |

**中国人的四个发音坑（每天跟读时自查）：**
1. **长音不够长**：おじさん（叔叔）vs おじいさん（爷爷），差一拍意思完全不同
2. **促音不顿**：いち（一）vs いっち（一致），促音必须空出一拍
3. **ら行**：既不是中文的 l 也不是 r，是舌尖轻弹上颚一下
4. **ふ**：不是"夫"，是双唇轻轻吹气（ふ 的发音接近 fu 但不咬唇）

### 阶段 1（第 3 周–第 3 月）：搭骨架

**主线**：《中日交流标准日本语》初级上册（共 24 课），约 2–3 课／周。

每周循环：
- 周一／三／五：新课文（语法点 → 单词 → 课文 → 练习）
- 周二／四：Anki 复习 + 课文朗读 3 遍
- 周六：听力 30 分钟 + 本周语法默写
- 周日：写一篇 100 字小短文（用本周语法点）

必学语法清单（阶段 1 内全部要过一遍）：

1. 判断句：～は～です／ではありません／でした
2. 存在句：～に～があります／います
3. 助词四大件：**は**（主题）**が**（主语）**を**（宾语）**に**（方向／对象）
4. 助词补充：**で**（场所／手段）**へ**（方向）**と**（并列）**の**（所属）**から／まで**（起止）**より**（比较）
5. 动词三类 + ます形／て形／た形／ない形
6. 形容词：い形（高い→高くない→高かった）、な形（静か→静かではない）
7. 请求与禁止：～てください／～てはいけません
8. 意愿与打算：～たい／～つもりだ
9. 授受动词：あげる／もらう／くれる（中国人的第一个大坎）
10. 敬体与简体：です・ます ↔ だ・である

**达标标准：**
- 能用日语完成 2 分钟自我介绍
- 看到标日初级上任意一课，能说出它的语法点
- 报名并通过 N5（N5 只考听读，无写作口语）

---

### 阶段 2（第 4–6 月）：能读懂简单真实材料

**主线**：《中日交流标准日本语》初级下册（第 25–48 课）。

新增能力：
- 简体（辞书形／た形／ない形）+ て形各种活用（てから・ても・ている・てしまう・ておく）
- 条件形：ば／たら／なら／と（四大条件句的区别是 N4 核心难点）
- 可能形、被动、使役、使役被动（这一串要专门花两周）
- 敬语入门：尊敬语（れる／られる、お～になる）与谦让语（お～する）
- 传闻与样态：そうだ 的两种用法（极易混淆）
- 推量：だろう／かもしれない／はずだ／ようだ

新增输入材料（从真实语料开始，不再只读教材）：
- **NHK NEWS WEB EASY**（nhk.or.jp/news/easy）：每天一篇，汉字全标假名，语速可调
- **にほんご多読ブックレット**：分级读物，Level 0–1 起步

**达标标准：**
- NHK Easy 一篇文章能读懂 80%，不懂的只剩生词而非语法
- 能写 300 字日记
- 报名并通过 N4

---

### 阶段 3（第 7–12 月）：从"学教材"到"用日语"

**主线**：《中日交流标准日本语》中级上册 + 大量原版输入。

三个转变：
1. **教材占比降到 40%**，其余时间给真实材料（日剧、YouTube、小说、新闻）
2. **开始输出**：每周至少 1 次真实对话（HelloTalk／italki／语伴）
3. **开始系统背 N3 语法**：用《TRY! 新日语能力考试 N3 语法必备》串一遍

输入材料升级：
- 日剧：从有中日双字幕 → 只留日文字幕 → 无字幕（选生活剧，别选悬疑和医疗）
- YouTube：**日本語の森**（免费 N5–N1 系统课）、日常 Vlog 频道
- 播客：通勤时泛听，不要求听懂，建立语感

**达标标准：**
- 生活类日剧不看字幕能跟上剧情
- 能写 500 字议论文（有观点 + 理由 + 例子）
- 通过 N3

---

### 阶段 4（第 13–24 月）：专业化

- 教材：标日中级下册 + N2 专项（词汇、语法、读解、听解四本分开练）
- 敬语系统学：这是职场日语的分水岭，商务敬语（二重敬语、謙譲語Ⅰ／Ⅱ）单独练
- 输出：每周 2 次口语实战 + 每周 1 篇 800 字
- 阅读：开始读原版轻小说／新闻社论

## 3. 每日时间表（工作日 90 分钟版）

| 时段 | 内容 | 时长 |
|---|---|---|
| ① | Anki 复习（蹲坑、通勤就能做） | 15 min |
| ② | 新课：语法 → 单词 → 课文 | 30 min |
| ③ | 朗读／影子跟读（shadowing） | 15 min |
| ④ | 听力（精听 10 min + 泛听 10 min） | 20 min |
| ⑤ | 输出：造句 5 句 或 写 3 行日记 | 10 min |

**时间不够时的优先级（从后往前砍）：** ⑤ → ④泛听 → ② → ③ → ①
**Anki 复习永远不能砍**，它是防止前面全白学的唯一保险。

### 周末（每次 2 小时）
- 周六：本周语法默写 + 错题重做 + 精听 1 篇
- 周日：输出日——写一篇短文，或找语伴聊 30 分钟

### 时间表调整
- 每天只有 30 分钟：只做 ①Anki（15）+ ②新课（15），进度减半，但别停
- 每天 2–3 小时：②、④ 各加倍，提前进入阶段 2 的真实材料

## 5. 中国人的专属陷阱（重点，反复看）

### 5.1 汉字陷阱

这些词你认识字，但意思是反的或完全不同的：

| 日语词 | 你以为 | 实际 |
|---|---|---|
| 手紙（てがみ） | 卫生纸 | **信** |
| 大丈夫（だいじょうぶ） | 大丈夫（男子汉） | **没问题／不要紧** |
| 娘（むすめ） | 姑娘 | **女儿** |
| 勉強（べんきょう） | 勉强 | **学习** |
| 丈夫（じょうぶ） | 丈夫 | **结实、坚固** |
| 野菜（やさい） | 野草 | **蔬菜** |
| 湯（ゆ） | 汤 | **热水／澡堂的水** |
| 我慢（がまん） | 我慢 | **忍耐** |
| 真面目（まじめ） | 真面目 | **认真、老实** |
| 気持ち（きもち） | 气 | **心情、感受** |
| 財布（さいふ） | 财布 | **钱包** |
| 検討（けんとう） | 检讨 | **研究、讨论** |

**对策：** 每遇到一个中日同形词，当场查一遍，确认意思是否一致。做一张"同形异义"卡片集，这是中国人专属的提分点。

### 5.2 语序陷阱

日语是 **SOV**（主宾谓），动词永远在最后：

> 私は　毎日　コンビニで　お弁当を　買います。
> 我　每天　在便利店　便当　买。

**训练法：** 听日语时，练"忍到句尾"——不要在听到主语时就开始猜意思，因为决定句子性质的是最后的动词（肯定／否定／过去／敬语）。

### 5.3 助词陷阱

は 和 が 的区别是日语最难的语法点之一，初学阶段记简化规则就够：

- **は**：提示主题，"关于 X 呢……"（后面说的是 X 的情况）
- **が**：提示主语，"是 X（不是别的）"／新信息／强调

例子：
- 私は寿司を食べる。（关于我，我吃寿司）
- 私が寿司を食べる。（吃寿司的是我，不是别人）

别在这个点卡死，先记住"は＝主题／が＝主语"，到 N3 会自然通透。

### 5.4 敬语陷阱

初学阶段只用 **です・ます**（敬体）就足够，不要过早学尊敬语和谦让语，会乱。
等 N4 过关、能听懂日常对话后，再系统学敬语——那时才有语境。

## 7. 八个常见坑

1. **罗马音依赖**——第 8 天起强制脱罗马音，否则听力永远起不来
2. **孤立背单词**——脱离句子的单词记不住，也用不出来
3. **只输入不输出**——"哑巴日语"是最常见的失败模式，第 1 个月就要开始写和说
4. **不复习**——没有 Anki，3 个月前的课全忘光，学 12 个月等于只学了 3 个月
5. **频繁换教材**——标日／大家的日语／Genki 选一套走到底，中途换教材等于重来
6. **过早啃生肉**——N3 前看无字幕动漫只会挫败，先分级读物
7. **忽视听力**——JLPT 听力占比 1/3，且是最难突击的部分，必须每天听
8. **追求完美发音再开口**——发音会随输入自然改善，不敢开口才是致命的
