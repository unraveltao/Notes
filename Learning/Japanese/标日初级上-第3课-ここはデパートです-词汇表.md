# 标日初级上 · 第 3 课《ここはデパートです》词汇表

> 依据教材词表整理：**42 词 + 2 句表达 = 44 条**（词表栏 42 条 + 右下表达栏 2 条），与课本词表逐条对齐，无遗漏。
>
> 表格结构：**表记**（下方「」内为释义）｜**读音**（假名，下方（）内为罗马音）｜**词性**｜**例句**（下方「」内为翻译）｜**记忆口诀**
>
> 例句以第 3 课语法（`ここ／そこ／あそこ／どこ`、`こちら／そちら／あちら／どちら`、`名は 名です`、`名も 名です`、`〜階`、`〜円`）为主。
>
> 词性缩写：**名**=名词　**代**=代词　**疑**=疑问词　**叹**=感叹词　**专**=专有名词
>
> 本课是第 2 课「こ・そ・あ・ど」的**场所版**：これ→ここ（这里），この→こちらの（这边）。同一个距离体系，换成"地点"就对了。

## 十、本课句型（可套用）

| 句型 | 意思 | 例句 |
|---|---|---|
| `ここ／そこ／あそこは 名です` | 这里／那里是〜 | ここはデパートです。<br>「这里是百货商店。」 |
| `名は どこですか` | 〜在哪里？ | 郵便局はどこですか。<br>「邮局在哪儿？」 |
| `名も 名です` | 〜也是〜 | ここもデパートです。<br>「这里也是百货商店。」 |
| `名は 名の 名です` | 〜的〜（所属） | これはデパートの入り口です。<br>「这是百货商店的入口。」 |
| `名は いくらですか` | 〜多少钱？ | この服はいくらですか。<br>「这件衣服多少钱？」 |
| `名は 〜階です` | 〜在〜楼 | 食堂は7階です。<br>「食堂在七楼。」 |

**5 个高频句：**

1. ここは　デパートです。「这里是百货商店。」
2. トイレは　どこですか。「厕所在哪儿？」
3. あそこも　銀行です。「那里也是银行。」
4. この傘は　いくらですか。「这把伞多少钱？」
5. 受付は　1階です。「接待处在一楼。」

## 十一、易错点

1. **ここ 和 こちら 的礼貌度不同**
   对朋友说 `トイレはどこ？`；对客人必须说 `トイレはどちらですか`。指路用 `あちらです`，不用 `あそこです`。
2. **「ビル」不是啤酒**
   `ビル`＝building（大楼），`ビール`＝beer（啤酒）。少一个长音，意思全变。
3. **「マンション」不是豪宅**
   日语 `マンション` 指钢筋混凝土的**普通公寓楼**；一栋独立小楼叫 `一戸建て（いっけだて）`。
4. **楼层读音有音变**
   1階＝いっかい、3階＝さん**がい**、6階＝ろっかい、8階＝はっかい。不是简单的 さんかい。
5. **「も」替换「は」，不叠加**
   `ここも デパートです` ✔　`ここはも デパートです` ✘
6. **「隣」是紧挨着，「周辺」是一圈**
   となり＝隔壁、紧邻；しゅうへん＝周边一带（范围更大）。

## 十二、外来语专题（本课 8 个）

| 日语 | 罗马音 | 原语 | 音变要点 |
|---|---|---|---|
| デパート | depaato | department store | 大幅缩写 + 长音 |
| マンション | manshon | mansion | -sion → ション |
| ホテル | hoteru | hotel | 词尾 -l → ル |
| コンビニ | konbini | convenience store | 只取前半 |
| レストラン | resutoran | restaurant | -au- → オ，词尾 -nt → ン |
| ビル | biru | building | 只取头两音节 |
| エスカレーター | esukareetaa | escalator | -tor → ター（长音） |
| コート | kooto | coat | -oa- → オー |

**规律复盘：**
- 日语极爱缩写长词：department store → デパート，convenience store → コンビニ
- 词尾 -r/-l → ル：hotel → ホテ**ル**
- 长音位置决定意思：ビル（大楼）／ビール（啤酒）

## 十三、使用建议

1. **把「こ・そ・あ・ど」的场所版和第 2 课的物品版对照背**：
   これ／ここ／こちら、それ／そこ／そちら——三列一起看，距离感一次到位。
2. **画一张自家周边地图**：用 `ここは〜です`、`隣は〜です`、`周辺は〜です` 描述，10 个句子就把本课名词用光了。
3. **场所名词按"生活半径"记**：先记自己常去的（コンビニ・病院・銀行・本屋），再记不常去的（バーゲン会場・マンション）。
4. **指路用语单独练**：`あちらです`、`2階です`、`となりです`——三句能应付 90% 的问路。
5. **数字＋楼层必须脱口而出**：1階〜10階 连着念三遍，音变自然就顺了。
