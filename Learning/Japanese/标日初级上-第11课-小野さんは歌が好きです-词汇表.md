## 十六、本课句型（可套用）

| 句型 | 意思 | 例句 |
|---|---|---|
| `名は 名が 好きです` | 某人喜欢某物 | 小野さんは歌が好きです。<br>「小野喜欢唱歌。」 |
| `名は 名が 嫌いです` | 某人讨厌某物 | 弟は野菜が嫌いです。<br>「弟弟讨厌蔬菜。」 |
| `名は 名が 上手／下手です` | 某人擅长／不擅长某事 | 李さんはピアノが上手です。<br>「小李钢琴弹得好。」 |
| `名は 名が 分かります` | 某人懂某事 | わたしは英語が分かります。<br>「我懂英语。」 |
| `名は 名が できます` | 某人会／能某事 | 森さんはスペイン語ができます。<br>「森会西班牙语。」 |
| `名や 名など` | 〜呀〜等等 | 肉や野菜などが好きです。<br>「喜欢肉、蔬菜等。」 |
| `〜から、〜` | 因为〜所以〜 | 寒いですから、窓を閉めます。<br>「因为冷，所以关窗。」 |
| `ですから、〜` | 所以〜 | 明日はテストです。ですから、今勉強します。<br>「明天考试，所以现在学习。」 |
| `どうして〜か` | 为什么〜？ | どうして歌が嫌いですか。<br>「为什么讨厌唱歌？」 |

**5 个高频句（背下来直接能用）：**

1. 小野さんは　歌が　上手です。「小野歌唱得好。」
2. わたしは　お酒が　好きでは　ありません。「我不喜欢喝酒。」
3. 李さんは　スポーツが　苦手です。「小李不擅长运动。」
4. 寒いですから、窓を　閉めます。「因为冷，所以关窗。」
5. 肉や　野菜などが　好きです。「喜欢肉、蔬菜等。」

## 十七、易错点

1. **好き・嫌い・上手・下手・苦手・分かる・できる 的对象用「が」，不用「を」**
   `歌が好きです` ✔　`歌を好きです` ✘　／　`日本語が分かります` ✔　`日本語を分かります` ✘
2. **好き／嫌い 是二类形容词，不是动词**
   否定是 `好きではありません`（不是 `好きません`）；修饰名词要加 `な`：`好きな歌`。
3. **「や」只列举部分，暗示还有别的**
   `肉や野菜` ＝「肉、蔬菜等」；全部列举用 `と`（`肉と野菜`＝只有这两样）。
4. **「から」表原因时放在句末谓语前，不是句首**
   `寒いですから、窓を閉めます` ✔　`から寒いです、窓を閉めます` ✘
5. **だから／ですから 是接续词，放句首**
   `明日はテストです。ですから、勉強します` ✔
6. **「脚」≠ 中文的"脚"**
   日语 `脚（あし）` 指**整条腿**；只指脚掌/脚踝用 `足（あし）`（同音，汉字不同）。
7. **上手 读 じょうず，不是 じょうしゅ**
   下手 读 へた（不是 したて）。这两个是训读特例，必须单独记。
8. **促音别漏**
   け**っ**こんしき、べ**っ**そう、け**っ**こうです——少一个小っ，读音和词义都会跑偏。
9. **ヒマワリ・バラ 不是外来语**
   是日语固有词，只是写成片假名。别按英语去猜。

## 二十、使用建议

1. **先拿下 6 个形2**：上手↔下手、好き↔嫌い、得意↔苦手，**正反成对背**，一次记两组。
2. **「が」句型当口头禅**：见到什么就问 `〜が好きですか`，一天就能把「が」练成肌肉记忆。
3. **频率副词做成一条轴**：いつも → よく → 時々 → たまに → あまり〜ない → 全然〜ない，按轴背比单个背快。
4. **名词分块记**：音乐 7、语言 2、运动 4、饮食 5、花草 4、场所 8——每块 5 分钟，四块一轮。
5. **外来语只记"音变规律"，别死记拼写**：-ck→ック、-f→フ、长音位置，掌握规律后新词能自己推。
6. **口诀只是拐杖**：谐音帮你抓发音轮廓，**背熟后一定要回到假名和罗马音**，别拿谐音代替读音。
